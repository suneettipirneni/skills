# Research for idioms, routing and designer workflow

Reviewed 2026-11-15. This extends [research.md](research.md). The catalog is an original synthesis of task decisions, not a validated automatic classifier. Sources below are primary practitioner/system documents unless explicitly labeled research. The adversary independently investigated additional sources and challenged applicability.

## Research questions and resulting decisions

| Question | Primary evidence inspected | Application and limit |
| --- | --- | --- |
| How do whole screens relate to primitives? | [Brad Frost, Atomic Design chapter 2](https://atomicdesign.bradfrost.com/chapter-2/) | Five concurrent levels; pages test actual content. No forced linear process or directory taxonomy. Foundations/workflow are this skill’s supporting organization. |
| Can patterns occur at multiple scales? | [Jenifer Tidwell, Common Ground](https://www.mit.edu/~jtidwell/common_ground_onefile.html), named sections inspected by the adversary | Overview Beside Detail, Central Working Surface and Repeated Framework inform context preservation and workspace composition. Historical 1999 concepts, not current ARIA or numerical authority. No claim to reading paid Designing Interfaces chapters. |
| How should dashboard composition vary? | [Bach et al., abstract](https://arxiv.org/abs/2205.00757), [author companion](https://dashboarddesignpatterns.github.io/patterns.html), independently inspected | Descriptive study of 144 dashboards and workshop with 23 participants supports multiple combinable structures. It does not establish one optimum or causal aesthetic thresholds. Full paper was not reanalyzed. |
| What makes table/cards/split different? | [Cloudscape view resources](https://cloudscape.design/patterns/resource-management/view/) | Common-attribute comparison, visual browsing and repeated contextual inspection are discriminants. Do not universalize its item-count cutoffs. |
| How do detail/edit idioms branch? | [Cloudscape details](https://cloudscape.design/patterns/resource-management/details/), [edit](https://cloudscape.design/patterns/resource-management/edit/), independently inspected | Simple detail, task panels and resource hub differ. Independent attribute editing differs from an interdependent multi-field commit. Enterprise context limits generalization. |
| Why distinguish empty states? | [Cloudscape empty states](https://cloudscape.design/patterns/general/empty-states/), independently inspected | No resources, filtered-out resources and missing values need different messages/recovery. Zero is not missing. Local button styling is not a universal prescription. |
| What separates a sequence from a task hub? | [GOV.UK task list](https://design-system.service.gov.uk/components/task-list/), [question pages](https://design-system.service.gov.uk/patterns/question-pages/) | Dependencies versus independent resumable tasks. One-question-per-page is contextual service guidance, not an expert-editor requirement. |
| What happens before and after commitment? | [Check answers](https://design-system.service.gov.uk/patterns/check-answers/), [confirmation pages](https://design-system.service.gov.uk/patterns/confirmation-pages/) | Review and durable receipts are separate from ephemeral success messages. Outcome wording must reflect actual transaction state. |
| What semantics hide behind visual names? | APG [listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/), [combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/), [tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/), [disclosure navigation](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/) | Interactive result descendants are not listbox options; comboboxes can be select-only; tabs are alternate panels; ordinary navigation is not automatically a menu. APG is implementation guidance, not proof of conformance. |
| Which primitives need distinct state models? | APG [button](https://www.w3.org/WAI/ARIA/apg/patterns/button/), [checkbox](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/), [radio](https://www.w3.org/WAI/ARIA/apg/patterns/radio/), [switch](https://www.w3.org/WAI/ARIA/apg/patterns/switch/), [toolbar](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/) | Action, pressed, independent/mixed selection, exclusive choice and binary on/off have different behavior. A visual row is not automatically a toolbar composite. |
| Does popover placement determine modality? | [Apple popovers](https://developer.apple.com/design/human-interface-guidelines/popovers/), [settings](https://developer.apple.com/design/human-interface-guidelines/settings/); APG modal dialog | Purpose, modality and presentation are separate decisions. Native compact adaptation must not be copied as universal web mechanics. |
| How should a designer choose activities? | [Design Council framework](https://www.designcouncil.org.uk/resources/framework-for-innovation/), GOV.UK [discovery](https://www.gov.uk/service-manual/agile-delivery/how-the-discovery-phase-works), [alpha](https://www.gov.uk/service-manual/agile-delivery/how-the-alpha-phase-works), independently inspected | Iterative framing/alternatives/evaluation; prototype risky assumptions. This skill scales those concepts to a task rather than requiring institutional project phases. |
| What fidelity answers a question? | [Kara Pernice, UX Prototypes: Low Fidelity vs. High Fidelity](https://www.nngroup.com/articles/ux-prototype-hi-lo-fidelity/), independently inspected | Visual, interaction and content fidelity are separate choices. A polished still cannot demonstrate recovery or keyboard behavior. No mandatory wireframe-to-high-fidelity sequence. |

## Andy Bell: integrated principles, not a name in the bibliography

The user clarified **Andy Bell**, not Adam Bell. [His author page](https://piccalil.li/author/andy-bell/) identifies his work in CSS, Piccalilli and Set Studio. The new [resilient-css route](foundations/resilient-css.md) integrates:

- [Build Excellent Websites](https://buildexcellentwebsit.es/): flexible browser rules and progressive enhancement. Applied to testing content/container variation and baseline behavior rather than selected screenshots only.
- [CUBE CSS](https://cube.fyi/) and its [composition](https://cube.fyi/composition.html), [utility](https://cube.fyi/utility.html), [block](https://cube.fyi/block.html) and [exception](https://cube.fyi/exception.html) documentation: locate the owning styling responsibility. CUBE and Atomic Design are different axes; no framework migration or CSS line-count gate is implied.
- Every Layout’s public [Stack](https://every-layout.dev/layouts/stack/), [Sidebar](https://every-layout.dev/layouts/sidebar/) and [Switcher](https://every-layout.dev/layouts/switcher/): contextual spacing and available-space adaptation, jointly authored with **Heydon Pickering**. Paid Cluster/Grid/Cover content was not accessible and is not represented as read.
- [Piccalilli article-layout case study](https://piccalil.li/blog/a-new-article-layout-and-better-options-for-advertisers/): content-role-specific width and a concrete practitioner response to feedback. Its exact grid and aesthetic choices are not universal rules.

These sources offer practitioner methods. The skill’s test fixtures, thresholds and feedback examples are authored applications, not empirical findings or statements attributed to Bell. Existing utilities, component CSS or Tailwind can support the principles; the skill evaluates behavior and ownership rather than tool allegiance.

## Conflicts and exclusions

- Atomic labels organize decisions; Tidwell’s patterns recur across scales. Allow direct entry, containment skips and scoped parallel concerns.
- Consistency supports recognition, but uniformity can obscure hierarchy or character. Local contracts require rationale and counterexamples.
- More visual polish can increase perceived usability without proving actual task success. Keep participant evidence separate from expert inspection.
- The APG tooltip page is explicitly a work in progress without task-force consensus; do not present it as settled normative requirements.
- Historical Welie accordion guidance was inspected by the adversary but its old numeric rules are not imported. Its catalog index returned inconsistent generic content; individual source integrity matters.
- Garrett’s original source could not be retrieved reliably. Paid course/book content and inaccessible sources are not claimed as read.
- Accessibility standards, platform conventions, expert suggestions, study observations and original synthesis remain distinct. Numerical values in examples come from declared local contracts unless a standard is explicitly cited.
