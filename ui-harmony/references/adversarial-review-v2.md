# Adversarial expansion review

Reviewed the staged UI Harmony skill, 2026-11-15. This is an independent expert review and synthetic tool exercise, not a usability study or a benchmark of automated classification.

## Verdict

Useful and proportionate for common product interfaces, editorial screens, transactions and focused control repairs. The catalog encodes consequential design decisions instead of just visual nouns. No remaining conceptual blocker after the requested repairs. It must continue to describe specialist domains as research boundaries and human route choice as judgment. It is a designer-support workflow, not the equivalent of validated product research or comprehensive specialist expertise.

## What forced changes

- The first choice atom stopped too early to distinguish a native select, select-only combobox, editable allowed-value chooser and free-entry input. The new selection matrix resolves these discriminants and adds current-value, asynchronous-option and focus-versus-selection acceptance.
- Overlay-to-form-section was originally a composition edge from a molecule to an organism. Moving it to related preserves the useful path without implying canonical containment. Atomic Design is now a concurrent mental model, not an implementation folder taxonomy or a mandatory build ladder.
- Workspace drag guidance originally asked only for keyboard alternatives. Added independent single-pointer alternatives correctly distinguish WCAG 2.5.7 from keyboard operability, including applicability exceptions.
- Workbench shortcut advice now preserves intentional text-editing commands while avoiding unrelated global interception.
- Malformed plan/catalog array fields previously threw TypeError. They now produce actionable validation diagnostics. Existing semantic-review malformed arrays/null entries were separately reported and repaired; direct retests now return diagnostics.
- A Don Norman source URL returned 404; the canonical hyphenated URL now replaces it.

## Practical applicability

**Dense operations dashboard:** Monitoring and collection paths preserve meaningful density and tabular comparison. The guidance separates a priority queue from vanity KPI composition and requires row-action scope, visible state and return context. Our clean phone dashboard had no automated findings but hid Status outside the initial table viewport; semantic review correctly locates the defect at collection-region. Dense data is not automatically clutter.

**Editorial:** Article, reading-region, typography and resilient-css allow content-role-specific widths and deliberate variation. This prevents uniform card wrappers and a single width applied blindly to prose, code and images. These are practitioner principles rather than numerical beauty laws.

**Mobile transaction/form:** Wizard versus task-hub, immediate versus explicit save, dependent answer invalidation, uncertain submission and durable receipt are operational distinctions. The review still needs real keyboard, recovery and submission tests; a screenshot can only assess visible relationships.

**Branded expressive surface:** The entrypoint and rules preserve type, density, imagery, asymmetry and purposeful optical correction. The contract mechanism can enforce a mistaken design if the reviewer chooses it badly; the skill explicitly requires rationale, alternatives and counterexamples. Clean geometry does not establish pleasantness. Earlier expressive typography fixture had nearly fused words despite clean metrics.

**Native/static evidence:** Useful for semantic diagnosis and platform-aware planning. DOM scripts are explicitly inapplicable to native trees/canvas; screenshot dimensions do not establish hit size, actual contrast or behavior. Unknowns remain explicit. This limitation is necessary calibration, not a failed implementation.

**One-control repair:** Direct atom entry selected only three references in the realistic icon task and one in the color task. No forced full workflow, persona exercise or taxonomy ceremony.

**New product:** Workflow modules require problem framing, evidence honesty, alternatives and uncertainty-driven prototyping. They do not invent interviews or prescribe a fixed institutional process. A task-specific route cannot replace contextual research.

## Source calibration

Independently researched Frost, Tidwell, Cloudscape, GOV.UK, Design Council, Kara Pernice, dashboard pattern research and APG. Source distinctions and unavailable paid material are disclosed in the research ledger. Spot-checked Andy Bell's Build Excellent Websites, CUBE composition and Every Layout Sidebar against the new route: flexible relationships, container context and component-independent composition are represented faithfully; Every Layout is jointly credited to Heydon Pickering and Andy Bell. Bell's illustrative values are not repackaged as universal thresholds. Framework choice is not treated as aesthetic proof.

Historical pattern descriptions, descriptive dashboard research, platform conventions, current accessibility requirements and original synthesis remain different evidence classes. The route catalog is not exhaustive. Scheduling, maps, canvas and media require explicit specialist research rather than generic-card prescriptions.

## Remaining limitations

The scripts validate declared contracts, coverage and report structure, not user value or aesthetic truth. The route tool intentionally performs no NLP inference. The adversarial scenarios are synthetic and not representative user trials. JSON completeness can be satisfied by false claims; located evidence still needs inspection. Browser geometry cannot fully evaluate optical balance, semantic priority, animation, task completion or distinctive character. The skill now states these boundaries rather than advertising a universal quality score.
